# otp

What Erlang/OTP does that a bench should, and how to stay compliant with Rat King's lexicons while
building it. The long form is [`docs/otp-and-at.md`](../../otp-and-at.md).

## Protocol

- One file per turn, `NNNN-<session>-<slug>.md`; the log is canonical, the files are rendered.
- One open question per turn. Short turns; depth lives in the doc.
- Decisions in `decisions.md`, voted append-only.
